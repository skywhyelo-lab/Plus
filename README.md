# Pulse website

Статический сайт Pulse. Покупка и выдача лицензий — только через https://t.me/Pulse_buy.
Серверных платежей, Firebase, токенов и обязательных npm-зависимостей здесь нет.

## Работа

Нужен Node.js 20 или новее. Установка пакетов не требуется.

Если npm отсутствует в PATH, используйте `node tools/serve.mjs`, `node tools/build.mjs` и `node tools/check.mjs` соответственно.

- `npm run dev` — собрать и открыть локальный сервер на http://127.0.0.1:4173. После изменения исходников перезапустите команду.
- `npm run build` — собрать главную страницу и каталог `public/` для публикации.
- `npm run check` — сборка и проверка ссылок, HTML, синтаксиса JS, документов и размера превью.

## Где редактировать

- `src/sections/` — контент главной, по одной секции в файле. Порядок задаёт числовой префикс. `00-head.html` содержит SEO и метаданные.
- `assets/css/site.css` — оформление сайта.
- `assets/js/site.js` — эффекты, переключение профилей и счётчики.
- `assets/js/demo.js` — интерактивное демо приложения.
- `assets/js/releases.js` — версия, размеры и хеши файлов из GitHub Releases.
- `eula.html`, `privacy.html`, `refund.html` — документы. Условия возврата в EULA должны совпадать с `refund.html`.
- `assets/images/pulse-preview-20260912.png` — превью ссылки, 1200 × 630, основанное на текущем первом экране.

`index.html` — результат сборки, напрямую не редактировать. Он сохранён в Git для простого просмотра; перед коммитом запускайте сборку.
`public/` — только публикуемые файлы, исключён из Git. `vercel.json` указывает Vercel использовать именно этот каталог.

## Публикация и превью

Загрузите этот каталог в Git и подключите репозиторий к Vercel. Переменные окружения не нужны.
При следующем обновлении превью используйте новое имя PNG и обновите оба адреса в `00-head.html` (Open Graph и Twitter), затем соберите сайт.
Telegram может сохранять старое превью уже отправленных сообщений: новый файл применяется после публикации и обновления кеша Telegram.
Старые webhook и `/api/*` удалены. В кабинетах прежних платёжных провайдеров можно отключить уведомления на эти адреса.
